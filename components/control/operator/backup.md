# Backup and restore

UI is stateless and follows the platform database backup procedure. Preserve
the approved build plus separately protected role credentials. No browser token
storage is part of a backup. MCP is stateless and requires only its scoped
credential/configuration to be restored.

Restore platform state in quarantine before mounting these surfaces. Disable
commands/dispatch/notifications until external execution outcomes are reconciled.
A copied UI does not make stale approved actions safe to run.
